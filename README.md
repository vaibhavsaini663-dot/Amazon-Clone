# 🛒 Amazon Clone — Frontend Project

A frontend clone of the Amazon homepage built using **HTML5 and CSS3**. This project recreates the familiar Amazon shopping interface with a navigation bar, search bar, promotional sections, product displays, and a detailed footer.

The project is created for learning and practicing frontend web development.

## 📌 Project Overview

The Amazon Clone provides a visual representation of an e-commerce website homepage. It focuses on page layout, styling, product presentation, and responsive design.

## ✨ Features

* **Navigation Bar:** Amazon-style logo, delivery location, search bar, account section, returns, and shopping cart.
* **Category Navigation:** Navigation panel with shopping categories and deals.
* **Promotional Sections:** Product offers and promotional cards.
* **Product Display:** Multiple product sections featuring different categories.
* **Amazon-Style Footer:** Information links, social media sections, customer support, and copyright information.
* **Font Awesome Icons:** Icons for search, location, shopping cart, and other interface elements.
* **Responsive Design:** CSS media queries for adapting the layout to different screen sizes.
* **Clean UI:** A familiar e-commerce layout inspired by Amazon.

## 🛠️ Technologies Used

* **HTML5** — Website structure.
* **CSS3** — Styling, layout, and responsive design.
* **Font Awesome** — Icons.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project Folder

```bash
cd Amazon-Clone
```

### 3. Run the Website

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a convenient development experience.

## 📱 Responsive Design

The project uses CSS media queries to adjust the layout for different screen sizes.

The responsive design targets:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

The layout adapts navigation elements, promotional cards, product sections, and footer columns to fit smaller screens.
